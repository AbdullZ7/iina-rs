## ما الجديد في 0.3.0

### خَرْج HDR حقيقي
- **عرض HDR حقيقي عبر Vulkan** على الشاشات الداعمة (ويندوز الآن، ولينكس على Wayland): الفيديو والواجهة يُدمجان بصيغة HDR10 (PQ / BT.2020)، والواجهة بسطوع ويندوز المعتاد للمحتوى العادي، مع رجوع تلقائي إلى OpenGL إن لم يتوفر.
- خيار لضبط ذروة سطوع الشاشة يدوياً (لأن ما تعلنه بعض الشاشات غير دقيق).
- جُرّب على جهاز حقيقي بعيّنات سطوع من 100 إلى 2000 نت.

### إعدادات الترجمة على طريقة PotPlayer
- اللغات المفضّلة، واختيار الخط من خطوط النظام مع البحث، والحجم والثخين، وألوان النص والحد والظل.
- سُمك الحد والظل، ومباعدة الحروف، وصندوق معتم أو خلفية.
- الموضع والهامش، وموضع الترجمة الثانوية، والترميز (كشف آلي أو Windows-1256…)، وتنسيق ASS.
- طريقة تحميل الترجمات الخارجية، والعرض في الأشرطة السوداء، وإزالة نصوص ضعاف السمع.
- ثلاث خطوات مزامنة (Z/X، Ctrl+Shift+Z/X، Ctrl+Alt+Shift+Z/X).

### نسخة ماك
- **أول نسخة لماك** (Apple Silicon، ملف dmg). النسخة غير موقّعة من Apple: انقر بالزر الأيمن ← فتح في أول مرة.

## What's new in 0.3.0

- **Real HDR output via Vulkan** on HDR displays (Windows now, Linux on Wayland): video and UI composited as HDR10 (PQ / BT.2020), UI at the OS SDR white level, automatic OpenGL fallback; manual peak-brightness override; verified on hardware with 100–2000 nit patches.
- **PotPlayer-style subtitle preferences**: preferred languages, system font picker with search, size / bold, text / outline / shadow colours and sizes, letter spacing, opaque / background box, position and margins, secondary subtitle position, encoding (auto-detect, Windows-1256…), ASS override, external subtitle loading, black bars, SDH removal, three sync steps.
- **First macOS build** (Apple Silicon dmg, not notarized: right-click → Open the first time).

**Downloads**: Windows (zip), Linux (tar.gz, deb), macOS (dmg).

## ما الجديد في 0.2.0

- **رسائل على الشاشة بأسلوب IINA بدل واجهة mpv المدمجة**: حجم الصوت، السرعة، موضع السعي، تبديل المسارات، التأخير، التكرار… وأُخفيت عناصر واجهة mpv الخاصة نهائياً.
- **إصلاح انعكاس الواجهة العربية**: شريط التحكم وشريط الوقت يبقيان باتجاه الوسائط المعتاد، والقوائم والنوافذ والنصوص محاذاة لليمين بشكل صحيح.

---

## What's new in 0.2.0

- IINA-style on-screen messages replace mpv's built-in OSD (volume, speed, seek position, track switches, delays, loops); mpv's own UI is gone.
- Fixed mirroring of the Arabic UI: media controls keep their direction, menus, windows and text align right properly.

**Downloads**: Windows (zip), Linux (tar.gz, deb).
